# NumPy Learnings

## Overview

This repository documents my learning journey with **NumPy**, one of the core libraries used for numerical computing in Python.

The goal of this repository is to build a strong understanding of NumPy by learning its concepts step by step, implementing examples, solving practice problems, and applying the concepts in real-world mini projects.

Rather than simply collecting code snippets, this repository represents my progress from learning NumPy fundamentals to using them in practical applications.

---

## Learning Objectives

- Understand NumPy arrays and their advantages over Python lists.
- Learn indexing, slicing, and array manipulation.
- Perform mathematical and statistical operations.
- Work with multidimensional arrays.
- Understand broadcasting and vectorized computations.
- Apply linear algebra concepts using NumPy.
- Learn file handling with `.npy` and `.npz` formats.
- Build practical projects using NumPy.
